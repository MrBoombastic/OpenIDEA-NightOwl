# Night Owl for OpenIDEA

A port of Sarah Drasner's acclaimed [Night Owl](https://github.com/sdras/night-owl-vscode-theme) theme for [OpenIDEA](https://github.com/l0ng-ai/openidea), copied directly from the IntelliJ IDEA theme plugin (_Material Theme UI_ by Elior Boukhobza / Mallowigi).

Ported to OpenIDEA by **MrBoombastic**.

Includes both:

- **Night Owl** (Dark theme) — deep twilight blue background (`#011627`), vibrant purple accent (`#7e57c2`), with warm syntax highlighting optimized for reading code late into the night.
- **Light Owl** (Light theme) — soft daylight surfaces (`#f0f0f0`), teal accent (`#2aa298`), and high-contrast, comfortable syntax.

---

## 🚀 Installation in OpenIDEA

### Option A: Install Plugin from Disk

1. In OpenIDEA, open **Settings › Plugins**.
2. Click the gear icon (⚙) in the top-right and choose **Install Plugin from Disk…**.
3. Select this directory (`OpenIDEA-NightOwl`) or its packaged zip.
4. Go to **Settings › Appearance** (or **Settings › Plugins**) and select **Night Owl**.

### Option B: Link for Development

You can link this folder directly into your OpenIDEA plugin registry:

```sh
openidea-plugin link
```

or add the directory path to `%APPDATA%\ai.l0ng.openidea\plugins\links.json`.
